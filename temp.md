## 👩‍💻 STEP 1: Learning & Technical Preparation (Must-Have Foundations)

### 1.1 HTML, CSS & JavaScript (Duration: 2 Weeks)
- HTML5, Semantic Tags
- CSS3, Flexbox, Grid, Media Queries
- JavaScript Fundamentals (ES6+)
- DOM Manipulation
- Fetch API, Async/Await
> Resources: MDN, FreeCodeCamp, Web Dev Simplified

### 1.2 React.js (Duration: 3 Weeks)
- Components, Props, State
- Conditional Rendering, Lists, Forms
- React Hooks (useState, useEffect, useRef)
- Routing (React Router v6)
- Context API / Redux Basics
- Custom Hooks (basic level)
> Resources: Codevolution, Namaste React, Scrimba React Course

### 1.3 Node.js + Express.js (Duration: 3 Weeks)
- Core Concepts of Node.js
- Express Routing
- REST API Development
- Middleware, Error Handling
- CRUD Operations
> Resources: CodeWithHarry Node Series, MDN Node.js, DevEd

### 1.4 MongoDB + Mongoose (Duration: 2 Weeks)
- MongoDB Installation and Compass
- Collections, Documents, Schemas
- CRUD using Mongoose
- Mongo Shell / MongoDB Atlas
- Relations using populate()

### 1.5 Authentication & Security (Duration: 1 Week)
- JWT-based Authentication
- Bcrypt for Password Hashing
- Role-based Access (Admin, User)
- CORS, Helmet, Rate Limiting

### 1.6 Deployment (Duration: 4 Days)
- Hosting Frontend: Vercel / Netlify
- Hosting Backend: Render / Cyclic.sh
- MongoDB Atlas Deployment
- Git & GitHub Best Practices

> 📌 Parallel: Learn Git, Postman, ThunderClient for API Testing
